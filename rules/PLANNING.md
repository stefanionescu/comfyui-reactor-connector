# Planning and evidence

Keep the full user scope in a local PLAN.md excluded from Git. Record completed work only when its stated
evidence exists. Describe blockers and remaining work without changing the
definition of completion to fit the implementation.

Resolve routine implementation choices from measured contracts. Continue within
existing authorization. Paid tests remain explicit tasks and share the recorded
budget; publication remains a separate action.

Use [plain language](PLAIN_LANGUAGE.md). Keep private account and machine details
out of public release evidence.
