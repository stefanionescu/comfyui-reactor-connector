Edit a video with X2

Open x2-01-edit-video, upload a short standard dynamic range (SDR) clip of at least 33 frames, and describe the edit. X2 requires a non-empty prompt and has no seed control. Select Run to save an edited video of your chosen length, without audio.

Use x2-02-reference-edit to add a subject reference. Upload the source video in Upload your source video and one reference picture in Upload your reference subject. State what to replace or transfer and what to preserve. Choose a reference whose subject is clearly visible and relevant to the source.

Inspect the beginning, middle, and end. The model may only partly apply a reference. Review the subject and background before keeping the result.

The pointer controls hold one normalized position for this run when enabled. Turn Live controls on to drag in the live panel. Keep queued frames affects source processing and can increase delay. Start with both options disabled. Source playback and pointer state are released during cleanup.

If no source is selected, upload a file before running. If the video has fewer than 33 frames, choose a longer clip. Changing Variation requests another paid execution. The Reactor model name is xmax/x2; the catalog's short label is x2.
